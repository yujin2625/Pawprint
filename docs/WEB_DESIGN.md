# Pawprint Web 설계 (초안)

> 상태: 설계 중. 구현 전.
> 최종 수정: 2026-10-08

Pawprint 청사진을 웹 브라우저(와 데스크탑 앱)에서 3D/2D로 보고 편집하는 편집기다.
마인크래프트 모드는 블럭 데이터를 추출하고 청사진을 주고받는 역할을 맡는다.

---

## 1. 구성

```
┌──────────────── 마인크래프트 + Pawprint 모드 ────────────────┐
│ ① 블럭 팩 내보내기 (.pawpack)   ② 청사진/초안 보내기·가져오기 (.pawprint) │
└───────────────┬───────────────────────────────┬────────────┘
                │ 파일                           │ 파일·공유 문자열
┌───────────────▼───────────────────────────────▼────────────┐
│ Pawprint Web (같은 코드)                                     │
│  - 웹사이트: GitHub Pages, 누구나 브라우저로 사용             │
│  - 데스크탑 앱: Tauri로 감싼 설치형 (Windows/macOS/Linux)     │
└────────────────────────────────────────────────────────────┘
```

- 서버가 없는 정적 웹앱이다. 블럭 팩·청사진은 모두 사용자 PC(브라우저 저장소 또는 앱 데이터 폴더)에만 저장된다.
- 코드는 Pawprint 저장소의 `web/` 폴더에 둔다. 청사진 형식 정의를 모드와 한곳에서 관리한다.

### 1.1 데스크탑 앱
- 웹 코드를 그대로 **Tauri**(Apache-2.0/MIT)로 감싼다. 설치 파일이 작다(수 MB~10MB대). 같은 기능을 Electron(MIT)으로도 만들 수 있지만 설치 크기가 100MB 이상이다.
- 웹에는 없는 데스크탑 전용 기능:
  - 설치된 마인크래프트(`.minecraft/versions/<버전>/<버전>.jar`)를 자동으로 찾아 **바닐라 블럭 팩을 바로 생성** (4장)
  - `.pawprint`, `.pawpack` 파일 더블클릭으로 열기
  - (나중) 모드와 로컬 연결로 바로 보내기
- 배포: GitHub Releases. 코드 서명이 없으면 Windows SmartScreen 경고가 뜬다(서명 인증서는 유료).

## 2. 라이선스·저작권

### 2.1 사용할 라이브러리 (확인 완료)
| 라이브러리 | 용도 | 라이선스 | 비고 |
|---|---|---|---|
| three.js | 3D 렌더링, 카메라, 레이캐스트 | MIT | |
| deepslate (misode) | blockstate·모델 해석, NBT 읽기/쓰기 | MIT | 의존성 gl-matrix(MIT), pako(MIT/Zlib), md5(BSD-3) |
| JSZip 또는 fflate | zip(.pawprint, .pawpack) | JSZip: MIT/GPLv3 중 선택(MIT로 사용), fflate: MIT | |
| Tauri | 데스크탑 앱 | Apache-2.0/MIT | |
| UI 프레임워크 (Svelte 또는 React) | 패널·목록 UI | 둘 다 MIT | 미정 |

- 모두 MIT/Apache 계열이라 Pawprint(MIT)에 넣어 공개·배포해도 문제없다. 각 라이선스 고지를 앱의 "오픈소스 라이선스" 화면과 저장소에 포함한다.
- **Blockbench는 GPL-3.0**이라 코드를 가져오지 않는다(참고만).

### 2.2 마인크래프트 에셋
- 바닐라 텍스처·모델은 Mojang 소유이고, EULA는 Mojang 동의 없이 게임 콘텐츠를 재배포하는 것을 금지한다. 사용 가이드라인의 허용 범위도 언제든 바뀔 수 있다.
- 따라서 **웹사이트에 바닐라 텍스처를 기본 탑재하지 않는다.** 모드 블럭 텍스처도 각 모드 제작자 소유라 마찬가지다.
- 대신 **각 사용자가 자기 게임에서 블럭 팩을 만들어 자기 브라우저에서만 쓴다** (4장).
- 사이트에 "Mojang/Microsoft와 무관한 비공식 도구" 문구를 넣고, 마인크래프트 로고는 쓰지 않는다.
- 블럭 팩 없이도 편집은 되게 한다. 이때는 블럭 ID로 정한 단색으로 표시한다(Mojang 에셋이 아닌 자체 색).

## 3. 다국어

### 3.1 원칙
- **언어를 파일 추가만으로 늘릴 수 있게** 만든다. 코드에 문장을 넣지 않는다.
- 모드: 이미 `assets/pawprint/lang/<언어>.json` 구조다. 새 언어 파일만 추가하면 된다. 블럭 검색 색인 언어도 설정(`searchLanguages`)으로 늘릴 수 있다.
- 웹: `web/src/i18n/<언어>.json`. **기본 언어는 영어**이고, 상단에 언어 선택 버튼을 둔다. 선택은 브라우저에 기억한다.
  - 번역이 빠진 문장은 영어로 대체한다.
  - 날짜·숫자 형식은 언어에 맞춘다(Intl API).
- 마인크래프트 언어 코드(`ko_kr`)와 웹 언어 코드(`ko`)는 대응표로 연결한다.

### 3.2 블럭 이름 언어
- 블럭 이름은 블럭 팩에 들어 있는 언어에서 가져온다.
- 표시 우선순위: 현재 웹 UI 언어 → 영어(`en_us`) → 블럭 ID
- 검색은 블럭 팩에 있는 **모든 언어 이름과 ID**로 된다(모드와 동일). 한국어 초성 검색도 지원한다.

## 4. 블럭 팩 (`.pawpack`)

### 4.1 만드는 방법
| 방법 | 대상 | 비고 |
|---|---|---|
| **모드에서 내보내기** | 바닐라 + 설치된 모든 모드 + 적용 중인 리소스팩 | 실제 게임과 똑같은 모습. 기본 방법 |
| **웹/앱에서 바닐라 jar로 생성** | 바닐라만 | 사용자가 자기 `<버전>.jar`를 선택(웹) 또는 자동 탐지(데스크탑). 모드 없이 바로 시작할 때 |

### 4.2 모드의 "블럭 팩 내보내기" 화면
- 라이브러리 화면의 버튼으로 연다.
- **언어 선택: 체크박스 다중 선택.** 게임에 설치된 언어 목록을 보여주고, 기본으로 `en_us`와 현재 게임 언어를 체크한다.
- 옵션:
  - 팩 이름 (기본: "모드팩 이름 + MC 버전")
  - 아이템 아이콘 포함 (팔레트용, 기본 켬)
  - 리소스팩 적용 상태 그대로 / 바닐라 리소스만
- 결과: `pawprint/packs/<이름>.pawpack`에 저장하고 폴더를 연다.

### 4.3 파일 구조 (zip)
```
example.pawpack
├─ pack.json           # 팩 정보 (아래)
├─ blocks.json         # 블럭 목록: ID, 속성과 가능한 값, 기본 상태, 아이템 여부, 렌더 레이어, 틴트 종류, 크리에이티브 탭
├─ lang/<언어>.json     # 블럭 ID → 이름 (선택한 언어만)
├─ icons.png + icons.json   # 팔레트용 아이템 아이콘 아틀라스 (선택)
├─ colors.json         # 기본 잔디·잎·물 색
└─ assets/<ns>/...     # 리소스팩과 같은 배치: blockstates, models/block, textures/block (+ .mcmeta)
```
**pack.json**
```json
{
  "format": 1,
  "id": "uuid",
  "name": "Better MC 5 (1.21.1)",
  "created": "2026-10-08T12:00:00Z",
  "mcVersion": "1.21.1",
  "dataVersion": 3955,
  "loader": "neoforge",
  "source": "mod-export",
  "mods": [{"id": "create", "name": "Create", "version": "6.0.0"}],
  "languages": ["en_us", "ko_kr"],
  "blockCount": 4210
}
```
- 블럭 모델이 실제로 참조하는 텍스처만 넣는다(용량 절감).
- 리소스팩 표준 배치라서 deepslate가 그대로 해석할 수 있다.

### 4.4 웹의 블럭 팩 관리
- 목록 보기 / 카드 보기 전환. 카드에는 이름, MC 버전, 로더, 모드 수, 언어, 블럭 수, 용량, 대표 블럭 미리보기가 나온다.
- 이름 변경, 삭제, 기본 팩 지정, 같은 팩의 새 버전으로 교체, 저장 공간 사용량 표시
- 저장: 웹은 IndexedDB, 데스크탑은 앱 데이터 폴더
- **청사진 만들 때 사용할 팩 선택.** 여러 팩을 겹쳐 쓸 수 있다(예: 바닐라 팩 + 모드팩 팩). 같은 블럭 ID가 겹치면 위에 둔 팩이 우선한다.
  - 청사진 파일에는 블럭 ID만 저장되므로 팩과 묶이지 않는다. "마지막에 쓴 팩" 정보만 힌트로 남긴다.
  - 열린 팩에 없는 블럭은 보라 상자로 표시하고 ID는 보존한다.

## 5. 청사진 형식 확장: 레이어 (`.pawprint` format 2)

그림 툴처럼 블럭을 레이어로 묶는다(예: 방, 지붕, 장식).

- `meta.json`에 레이어 목록을 둔다: `id, 이름, 색 태그, 보임, 잠금, 순서, 부모 그룹(폴더)`
- `blueprint.nbt`에 블럭마다 레이어 번호를 둔다(블럭 위치 배열과 같은 순서의 `Layers` 배열). 제거할 블럭도 레이어를 가진다.
- 한 칸에는 블럭이 하나뿐이다. 레이어는 "어느 묶음에 속하나"를 나타내는 정보이고, 칸이 겹치지 않는다. 다른 레이어의 칸에 블럭을 놓으면 그 칸이 현재 레이어로 옮겨진다.
- 형식 버전을 2로 올린다.
  - 새 모드는 1과 2를 모두 읽는다.
  - 1을 읽으면 레이어 하나("기본")로 취급한다.
  - 옛 모드는 2를 "너무 새 형식"이라며 거부한다(지금도 그렇게 막아 둠).
- 다른 포맷(.litematic 등)으로 내보낼 때는 레이어 정보가 빠진다.

## 6. 웹 편집기

### 6.1 화면 구성
```
┌ 상단: 파일 · 편집 · 보기 · 블럭 팩 · 언어 ───────────────────────────────┐
│ 도구 막대 │        뷰포트 (3D / 2D / 3D+2D 나란히)        │ 레이어 패널   │
│ (세로)    │                                              │ 팔레트 패널   │
│           │                                              │ 속성·재료 패널 │
└ 하단: 좌표 · 선택 크기 · 블럭 수 · 현재 층/단면 ─────────────────────────┘
```

### 6.2 3D 보기 (전체를 보면서 배치)
| 조작 | 동작 |
|---|---|
| 우클릭 누른 채 W/A/S/D | 수평 이동 (유니티 기준 x·z) |
| 우클릭 누른 채 Q/E | 아래/위 이동 (y) |
| 우클릭 + 마우스 이동 | 시점 회전 |
| 우클릭 + 휠 | 이동 속도 조절 |
| 휠 (우클릭 없이) | 바라보는 방향 앞뒤 이동 |
| 휠 클릭 드래그 | 화면과 평행 이동 |
| F | 선택 영역(없으면 전체)으로 카메라 맞추기 |
| 좌클릭 | 현재 도구 사용 (놓기·선택 등) |
| 블럭 면에 커서 | 놓일 자리 미리보기 |

### 6.3 2D 보기 (단면을 보면서 수정)
- 단면 방향: Y(평면도), X·Z(입면도) 전환
- 층 이동: `PgUp/PgDn` 또는 `[ ]`, 하단 슬라이더
- **어니언 스킨 켜기/끄기**: 아래층(기본), 위층 표시를 각각 선택하고 투명도 조절
- 휠: 확대/축소, 휠 클릭 드래그: 화면 이동
- 칸 그리드와 좌표 눈금, 중심선 표시

### 6.4 도구
| 도구 | 2D | 3D | 설명 |
|---|---|---|---|
| 연필(브러시) | O | O | 브러시 모양대로 칠하기. 3D에서는 커서가 닿은 면 위 평면에 칠함 |
| 지우개 | O | O | 브러시 모양대로 지우기 |
| 채우기(양동이) | O | △ | 같은 블럭으로 이어진 영역 채우기. 3D는 같은 층·면 기준 |
| 선 | O | O | |
| 사각형 / 원(타원) | O | O | 채움/테두리 선택. 3D에서는 면 평면 기준 |
| 상자·속빈 상자·벽·구·원기둥 | - | O | 모드와 같은 도형 |
| 선택 | O | O | 상자 선택, 같은 블럭 선택(마법봉), 레이어 전체 선택 |
| 이동·회전·반전 | O | O | 선택 영역 변형 |
| 복사·붙여넣기 | O | O | |
| 스포이트 | O | O | 블럭 집기 (휠 클릭과 동일) |
| 바꾸기 | O | O | 선택 영역 또는 전체에서 블럭 A→B (속성 유지) |
| 스탬프 | O | O | 저장해 둔 블럭 묶음을 그대로 찍기 (6.5) |

- **브러시 모양**: 사각형, 원, 마름모, 사용자 정의 브러시(선택 영역 단면을 브러시로 저장). 크기 슬라이더, 2D와 3D 공용
- 블럭 상태 편집: 방향·위아래·축 등 속성을 팔레트 옆에서 바꾸거나 회전 키로 바꿈
- 실행 취소 / 다시 실행, 작업 기록 패널

### 6.5 스탬프 (미리 만든 블럭 묶음)
- 선택 영역을 "스탬프로 저장"하거나, 라이브러리의 다른 청사진을 스탬프로 쓴다.
- 3D/2D 모두에서 커서 위치에 미리보기와 함께 찍는다. 회전·반전 키 지원.
- 스탬프 목록 패널: 썸네일, 검색, 즐겨찾기

### 6.6 레이어 패널
- 목록: 보임(눈), 잠금, 색 태그, 이름, 블럭 수
- 드래그로 순서 바꾸기, 그룹(폴더)으로 묶기·접기
- 새 레이어, 복제, 합치기, 삭제, 이름 변경
- 현재 레이어(새 블럭이 들어갈 곳) 지정
- 선택 영역을 다른 레이어로 옮기기
- 레이어만 보기(솔로), 다른 레이어 흐리게
- 재료 목록을 레이어별로도 보기

### 6.7 팔레트 패널
- 블럭 아이콘 그리드, 검색(모든 언어 + ID + 초성), 크리에이티브 탭별 분류, 모드별 필터
- 즐겨찾기, 최근 사용
- 팩에 없는 블럭은 경고 표시

### 6.8 파일
- 열기·저장: `.pawprint` (모드와 같은 형식), 공유 문자열(PAW1) 붙여넣기·복사
- 가져오기·내보내기: `.litematic`, `.schem`, `.nbt` (모드의 변환 규칙과 동일하게)
- 자동 저장: 작업 중인 청사진을 브라우저 저장소에 주기적으로 저장
- 웹 안 프로젝트 목록 (목록/카드 보기, 썸네일)

### 6.9 렌더링·성능
- three.js로 그린다. 블럭 모델은 deepslate로 blockstate → 모델 → 면 목록으로 해석한 뒤 three.js 메시로 만든다.
- 16×16×16 구역 단위 메시 캐시와 바뀐 구역만 다시 만들기(모드와 같은 방식). 메시 생성은 Web Worker에서 한다.
- 텍스처는 블럭 팩에서 아틀라스로 묶고, 애니메이션 텍스처(.mcmeta)는 지원한다.
- 별도 렌더러로 그려지는 블럭(상자, 표지판, 침대, 현수막 등), 물·용암, 연결 텍스처(CTM) 모드는 처음엔 대체 표시를 쓴다.

## 11. 시각 디자인 (2026-10-08)

### 11.1 테마
- 기본 테마 **"청사진(Blueprint)"**: 청사진 파랑 바탕과 격자, 크림색 패널, 호박색 강조색.
- 기본 제공: 청사진(기본), 다크, 라이트.
- **테마 설정 창**에서 UI의 주요 색을 직접 바꿀 수 있다. 기본 제공 테마를 복사해 수정하고, 저장, 이름 변경, 삭제, 초기화, JSON 파일로 내보내기·가져오기(공유)를 지원한다.
- 바꿀 수 있는 색(모두 CSS 변수로 구현):

  | 키 | 쓰임 |
  |---|---|
  | `bg` | 화면 바탕 |
  | `panel`, `panel-border` | 패널 배경과 테두리 |
  | `text`, `text-muted` | 기본 글자, 보조 글자 |
  | `accent`, `on-accent` | 강조색(선택, 주요 버튼), 그 위 글자 |
  | `viewport-bg`, `grid` | 3D/2D 뷰포트 배경과 격자선 |
  | `selection`, `preview` | 선택 영역, 놓일 자리 미리보기 |
  | `danger`, `warning`, `success` | 오류, 경고(팩에 없는 블럭 등), 완료 |
- 글자와 배경의 명암비가 낮으면 테마 설정 창에서 경고를 띄운다.

### 11.2 강조색
- 기본은 **호박색**(`#EF9F27`, 그 위 글자 `#412402`). 파란 바탕의 보색이라 뷰포트의 선택 테두리와 미리보기가 잘 보인다. 테마 설정에서 바꿀 수 있다.

### 11.3 글꼴
- 기본 글꼴: **Silver** (Poppy Works, CC BY 4.0). 한국어·일본어·중국어·키릴·그리스·조지아·라틴 등 지원.
  - 웹 배포 시 유니코드 영역별 WOFF2로 나눠 필요한 글자만 내려받는다(`unicode-range`).
  - 픽셀 글꼴이라 UI 글자 크기를 원본 크기의 정수배로 맞춘다.
  - "크레딧·라이선스" 화면에 출처(Poppy Works, CC BY 4.0)를 표시한다.
- **사용자 글꼴 추가**: 설정에서
  - 글꼴 파일(.ttf/.otf/.woff2) 올리기 → 브라우저 저장소에 보관
  - 웹 글꼴 링크 추가(예: Google Fonts CSS 주소, 글꼴 파일 주소)
  - 언어별로 어떤 글꼴을 먼저 쓸지 순서를 정한다. Silver에 없는 글자는 지정한 글꼴로, 그것도 없으면 시스템 글꼴로 대체된다.

### 11.4 로고
- 발바닥 + 청사진 모티브로 새로 만든다(마인크래프트 로고·텍스처는 쓰지 않음).
- **완전 도트(픽셀 아트)** 이미지로 만든다.
- **결정: "청사진 고양이"** — 두루마리 청사진 위로 고개를 내민 호박색 고양이(24×24 도트). 작은 크기에서 덜 보이는 점은 감수한다.
- 고양이는 마스코트로도 쓴다: 첫 방문 소개, 빈 화면 안내(블럭 팩 없음, 프로젝트 없음), 오류 화면 등. 파비콘(16·32px), 앱 아이콘, 가로형 로고(아이콘 + "Pawprint" 글자)까지 만든다.

### 11.5 첫 방문 소개
- 처음 방문했을 때만 소개 화면을 보여준다: 무엇을 하는 도구인지, 블럭 팩 만드는 법(모드 / 마인크래프트 jar), 기본 조작.
- 이후에는 바로 편집기(또는 마지막 프로젝트)로 들어간다.
- 설정 → "소개 다시 보기"로 언제든 다시 볼 수 있다.
