# Pawprint 설계 문서

> 상태: 1단계(MVP) + 2단계 일부(편집 모드, 도형 도구, 팔레트) + AI 텍스트 형식 구현, 게임 내 확인 중
> 최종 수정: 2026-10-07 (0단계 완료)

## 1. 개요

Pawprint는 **클라이언트 전용** 건축 계획 모드다.

- **청사진(Blueprint) 편집**: 가짜(ghost) 블럭을 미리 배치해 보고 저장한다.
- **배치(Placement) 오버레이**: 저장한 청사진을 월드에 띄워 어디에 어떤 블럭을 놓아야 하는지 보여준다.
- **라이브러리**: 청사진을 목록/그룹/정렬/필터/검색으로 관리하고, 파일이나 문자열로 공유한다.

주 사용 환경은 **다른 사람이 운영하는 멀티플레이 서버**다. 서버에 이 모드를 설치하지 않아도 동작해야 한다.

### 목표
- 서버에 아무것도 설치하지 않고 동작한다 (네트워크 채널 없음).
- 여러 로더(Fabric / NeoForge / Forge)와 여러 MC 버전을 지원한다.
- 접속한 환경에 등록된 블럭을 그때그때 인식한다. 어떤 모드팩에서도 동작한다.
- 다른 청사진 모드 포맷과 최대한 호환한다.
- 기본 언어는 영어이고, 게임 언어가 한국어면 한국어로 표시한다.

### 비목표 (의도적으로 하지 않음)
- **자동 설치(printer), 설치 보조(easy place)**: 대부분의 서버에서 핵으로 취급하므로 넣지 않는다.
- 서버 측 기능 (서버 플러그인/모드 연동).
- 플러그인 서버의 커스텀 블럭(ItemsAdder, Oraxen 등) 인식.

## 2. 지원 플랫폼

| 단계 | MC 버전 | 로더 | 비고 |
|---|---|---|---|
| 1차 | 1.21.1 | NeoForge, Fabric | 개발/테스트 기준 (BMC5 팩) |
| 2차 | 1.20.1 | Forge, Fabric | 모드팩 수가 가장 많은 버전 |
| 3차 | 최신 버전 | NeoForge, Fabric | 렌더링 구조 변경 대응 필요 |

### 빌드 구조
- [MultiLoader-Template](https://github.com/jaredlll08/MultiLoader-Template) 구조를 따른다.
  - `common`: ModDevGradle의 NeoForm(바닐라) 모드로 컴파일한다. 매핑은 Mojang 공식 + Parchment.
  - `fabric`: Fabric Loom. `neoforge`: ModDevGradle.
  - 로더 모듈은 빌드할 때 `common` 소스를 함께 컴파일해서 jar 하나로 낸다.
- **Stonecutter**(MC 버전별 분기)는 두 번째 MC 버전(1.20.1)을 붙이는 시점에 도입한다.
  버전이 하나뿐인 지금은 빌드를 단순하게 둔다.
- 런타임 의존 모드(Architectury API 등)는 두지 않는다. 사용자가 이 모드 하나만 넣으면 되게 한다.
  플랫폼 차이는 자체 `Platform` 인터페이스(`ServiceLoader`)로 추상화한다. Fabric 쪽은 Fabric API만 필요하다.
- 클라이언트 전용 선언: Fabric `"environment": "client"`, NeoForge `@Mod(dist = Dist.CLIENT)` + `displayTest = "IGNORE_ALL_VERSION"`.
- 패키지: `com.dumaru.pawprint`.
- 개발 빌드: `build-and-install.bat`가 빌드 후 NeoForge jar를 BMC5 인스턴스 `mods`에 복사한다.
- CI: GitHub Actions가 푸시마다 빌드하고 jar를 아티팩트로 올린다.

```
Pawprint/
├─ common/        # 로더 무관 로직 (대부분의 코드)
│  ├─ format/     # 청사진 데이터 모델, 자체 포맷, 외부 포맷 변환
│  ├─ library/    # 인덱싱, 검색, 정렬, 필터, 그룹
│  ├─ placement/  # 배치 상태, 월드 비교(diff), 재료 계산
│  ├─ edit/       # 편집 도구, 실행 취소/다시 실행
│  ├─ studio/     # 스튜디오 월드 생성, 지형 스냅샷, 차이 추출
│  ├─ palette/    # 블럭 목록 수집, 분류, 검색
│  ├─ render/     # 렌더러 추상 인터페이스
│  ├─ ui/         # 화면 로직 (GUI 래퍼 위에서 동작)
│  └─ platform/   # 로더 추상화 인터페이스
├─ fabric/        # Fabric 진입점, 이벤트 연결
├─ neoforge/      # NeoForge 진입점, 이벤트 연결
├─ forge/         # Forge 진입점 (1.20.1)
└─ docs/
```

### 버전별로 깨지기 쉬운 부분
- **렌더링**: 1.21.2 이후, 1.21.5~1.21.6 즈음에 렌더링 구조가 크게 바뀌었다.
  가짜 블럭 렌더러는 `GhostRenderer` 인터페이스 뒤에 두고 버전별 구현을 갈아 끼운다.
- **GUI API**: 얇은 래퍼로 감싼다.
- **Sodium / Iris**: 로더와 버전마다 따로 테스트한다. 셰이더 환경용 와이어프레임 대체 렌더링을 둔다.

## 3. 핵심 개념

| 용어 | 설명 |
|---|---|
| Blueprint (청사진) | 블럭 배치 계획 한 개. 설치할 블럭과 제거할 블럭을 담는다. |
| Placement (배치) | 청사진을 특정 서버/차원/좌표에 띄운 것. 회전, 반전, 진행 상태를 가진다. |
| Studio (스튜디오) | 로컬 싱글 크리에이티브 공허 월드. 진짜 블럭으로 편하게 설계하는 공간. |
| Snapshot (지형 스냅샷) | 서버에서 클라이언트에 로드된 주변 지형을 복사한 것. 스튜디오에 깔아 쓴다. |
| Library (라이브러리) | 저장된 청사진 전체. 인스턴스 폴더에 있고 월드/서버와 무관하다. |

## 4. 기능 상세

### 4.1 서버 위 편집 모드 (In-world Edit)
서버에 접속한 상태에서 실제 월드 위에 가짜 블럭을 배치한다. 서버에는 아무것도 보내지 않는다.

- **배치/제거**: 가짜 블럭을 놓고 지운다. 실제 블럭 자리를 "제거할 블럭"으로 표시할 수도 있다.
- **블럭 상태**: 실제 설치 규칙(`getStateForPlacement`)으로 방향 등을 계산한다. 회전/반전 키로 직접 바꿀 수도 있다.
- **프리캠**: 카메라만 떼어 움직인다. 플레이어 위치 패킷은 보내지 않는다. 설정으로 끌 수 있다.
- **월드 숨기기 토글**: 실제 블럭을 숨기거나 흐리게 해서 빈 공간처럼 편집한다.
- **편집 도구**: 실행 취소/다시 실행, 박스/선/벽 채우기, 복사/붙여넣기, 바꾸기(A→B), 대칭 편집.
- **층(Y) 보기**: 지정한 높이 위를 숨긴다.
- **월드에서 캡처**: 영역을 지정해 이미 지어진 건물을 청사진으로 저장한다.

### 4.2 스튜디오 (Studio)
로컬 싱글 크리에이티브 공허 월드에서 진짜 블럭으로 설계한다.

**흐름**
1. 서버에서 **지형 스냅샷**을 찍는다 (4.3).
2. "스튜디오 열기"를 누르면 서버 접속을 끊고 스튜디오 월드를 만들거나 연다.
3. 스냅샷 지형을 **원래와 같은 좌표**에 깐다.
4. 크리에이티브 모드로 자유롭게 건축한다.
5. "청사진으로 저장"을 누르면 **스냅샷과 달라진 부분만** 추출한다.
   - 새로 놓은 블럭은 "설치할 블럭"이 된다.
   - 스냅샷에 있던 블럭을 부순 자리는 "제거할 블럭"이 된다.
6. 청사진에 원래 서버 주소, 차원, 좌표를 기록한다.
7. "서버로 돌아가기"를 누르면 마지막 서버에 다시 접속한다. 이어서 "원위치 배치"를 하면 정확한 자리에 오버레이가 뜬다.

**스튜디오 월드 설정**
- 저장 위치: `saves/pawprint_studio_<id>/`. 타이틀 화면이나 라이브러리에서 연다.
- 공허 월드, 크리에이티브, 치트 허용.
- 게임 규칙: `randomTickSpeed 0`(잔디 번짐, 잎 소멸 방지), `doDaylightCycle false`, `doWeatherCycle false`, `doMobSpawning false`, `doFireTick false`.
- 지형을 깔 때는 블럭 업데이트 없이 설치한다 (모래 낙하, 물 흐름 방지).
- 스튜디오는 통합 서버(같은 JVM)에서 돌아가므로, 서버 측 월드에 직접 블럭을 설치해도 된다.
- 스냅샷 없이 빈 스튜디오로 시작할 수도 있다.

### 4.3 지형 스냅샷 (Terrain Snapshot)
서버에서 **클라이언트에 이미 로드된 청크**의 블럭 정보를 읽어 로컬에 저장한다. 서버에 요청을 보내지 않는다.

- **표면 모드 (기본)**: 지표면 아래 N칸(설정 가능, 기본 4)부터 그 위에 있는 것 전부를 가져온다.
  - 서버의 광물 투시 방지(anti-xray)가 지하에 보내는 가짜 광석을 자연스럽게 피할 수 있다.
- **박스 모드**: 지정한 영역 전체를 가져온다 (지하 건축용).
- 반경 제한(설정 가능, 기본 8청크). 기능 전체를 끌 수 있다.
- 가져오는 것: 블럭 상태, 바이옴, 표지판 글자 등 클라이언트가 아는 블럭 엔티티 데이터.
- 가져오지 못하는 것: 상자 등 컨테이너 내용물, 로드되지 않은 청크.
- 맵 다운로드를 금지하는 서버도 있으므로 설정 화면에 안내 문구를 둔다.

### 4.4 배치 오버레이 (Placement)
- **배치 조작**: 기준점 지정, 회전/반전, 방향키로 미세 이동, 잡고 끌기, "원위치 배치".
- **상태별 색상**
  | 상태 | 표시 |
  |---|---|
  | 놓아야 할 곳 | 반투명 가짜 블럭 |
  | 다른 블럭이 있음 | 빨강 |
  | 블럭은 맞는데 상태(방향 등)가 다름 | 노랑 |
  | 제거해야 할 블럭 | 주황 테두리 |
  | 정확히 놓음 | 숨김 (설정 시 초록) |
- **층 보기**: 현재 층만 표시하고 "다음 층" 키로 넘긴다.
- **가장 가까운 미설치 블럭** 강조.
- **진행률**(%) 표시.
- **다중 배치**: 여러 청사진을 동시에 띄운다.
- **저장**: `서버 주소 + 차원` 기준으로 로컬에 저장해서 재접속해도 유지한다.
- **선택 연동**: Xaero 미니맵/JourneyMap이 있으면 배치 위치를 웨이포인트로 등록한다.

### 4.5 재료 목록 (Material List)
- 블럭별로 필요 수량, 인벤토리 보유량, 남은 수량을 표시한다.
- 블럭을 아이템으로 바꾸는 규칙: `getCloneItemStack` 기반으로 하고, 문/침대/이중 반블럭 등 예외 처리를 둔다.
- 텍스트/CSV로 내보낸다.
- 인벤토리 기준으로만 계산한다 (상자 내용물은 알 수 없음).

### 4.6 블럭 팔레트 (Palette)
**인벤토리와 상관없이** 게임에 등록된 모든 블럭을 고를 수 있다.

- 접속할 때마다 블럭 레지스트리를 읽어 목록을 만든다. 하드코딩하지 않는다.
- 기본으로는 아이템 형태가 있는 블럭만 보이고, 기술용 블럭(공기, 피스톤 머리 등)은 숨긴다.
  "고급: 모든 블럭 보기" 토글로 숨긴 블럭도 볼 수 있다.
- **분류**: 크리에이티브 탭 구성을 재사용한다 (모드 탭 포함). 모드별 필터, 최근 사용, 즐겨찾기.
- **상태 편집**: 팔레트에서 방향, 반블럭 위/아래 등 블럭 상태를 바로 바꾼다.
- **블럭 검색 (게임 언어와 무관)**: 게임 언어가 한국어든 영어든 **한글 이름, 영어 이름, 블럭 ID** 모두로 찾을 수 있다.
  - 현재 게임 언어와 별개로 리소스에서 `en_us`와 `ko_kr` 번역 표를 둘 다 읽어 검색 색인을 만든다
    (`ClientLanguage.loadFrom` 같은 방식으로 따로 로드하며, 게임 언어는 바꾸지 않는다).
  - 리소스팩이나 모드를 다시 불러오면 색인을 다시 만든다.
  - 한국어 번역이 없는 모드 블럭은 영어 이름과 ID로만 검색된다.
  - 한글 초성 검색(`ㅊㄴㅁ` → 참나무)도 게임 언어와 상관없이 항상 켜져 있다.
  - 표시 이름은 현재 게임 언어를 따른다. 검색어가 다른 언어 이름에 걸렸으면 그 이름을 보조 텍스트로 함께 보여준다.
  - 추가 언어 색인은 설정에서 늘릴 수 있게 한다 (기본: `en_us`, `ko_kr`).
- **서버 호환 표시**
  | 서버 종류 | 처리 |
  |---|---|
  | 모드 서버 (레지스트리 동기화됨) | 전부 사용 |
  | 바닐라/플러그인 서버 | `minecraft:` 외 블럭에 "이 서버에서 설치 불가" 표시, 숨김 옵션 |
  | 공통 | 서버에서 꺼진 실험적 기능 블럭은 제외 |

### 4.7 라이브러리 (Library)
- **저장 위치**: `<게임 폴더>/pawprint/blueprints/`. 하위 폴더 구조가 곧 그룹이다.
  탐색기에서 파일을 직접 옮겨도 반영된다.
- **메타데이터**: 이름, 설명, 태그, 작성자, 생성/수정일, 크기, 블럭 수, 사용 모드 목록, MC 버전, 원위치 정보.
- **썸네일**: 저장할 때 자동으로 렌더링해서 캡처한다.
- **보기**: 목록 보기, 그리드(썸네일) 보기, 그룹(폴더) 보기.
- **정렬**: 이름, 수정일, 생성일, 크기, 블럭 수, 최근 사용.
- **필터**: 태그, 그룹, 크기 범위, 특정 블럭 포함, 특정 모드 사용, 현재 인벤토리로 지을 수 있는 것, 현재 서버에서 설치 가능한 것.
- **검색**: 이름, 태그, 설명, 포함된 블럭. 블럭은 4.6과 같은 색인을 써서 게임 언어와 상관없이 한글 이름, 영어 이름, ID로 찾는다. 초성 검색은 항상 지원한다.
- **즐겨찾기, 최근 사용**.
- **인덱스 캐시**: `pawprint/index.json`에 메타데이터를 캐시하고, 파일 수정 시각으로 갱신한다.

### 4.8 공유 / 가져오기 / 내보내기
- **파일 내보내기**: 청사진 한 개를 파일로 내보낸다.
- **공유 문자열**: `PAW1:` + Base64URL(Deflate(청사진 NBT)). 썸네일은 뺀다.
  디스코드 등에 바로 붙여넣을 수 있다. 크기 상한을 두고, 넘으면 파일 공유를 안내한다.
- **드래그 앤 드롭**: 게임 창에 파일을 끌어다 놓으면 가져오기 화면이 뜬다.
- **안전장치**: 가져올 때 압축 해제 크기, NBT 깊이, 블럭 수에 상한을 둔다 (압축 폭탄 방지).

**포맷 호환**
| 포맷 | 사용처 | 가져오기 | 내보내기 |
|---|---|---|---|
| `.pawprint` (자체) | 기본 저장 | O | O |
| `.litematic` | Litematica | O | O |
| `.schem` (Sponge v2/v3) | WorldEdit, FAWE | O | O |
| `.nbt` (바닐라 구조물) | 구조 블럭, Create | O | O |
| `.schematic` (MCEdit) | 1.12 이하 | O (ID 변환표, 손실 있음) | X |
| `.bp` (Axiom) | Axiom | 포맷 공개 범위 확인 후 결정 | 확인 후 결정 |
| 공유 문자열 | 채팅 공유 | O | O |

- 외부 포맷으로 내보내면 메타데이터(태그, 썸네일 등)가 빠진다. 원본은 항상 자체 포맷으로 둔다.
- "제거할 블럭"은 외부 포맷에서 공기 블럭으로 표현한다 (지원하는 포맷만).

### 4.9 다국어
- 기본 `en_us.json`, 추가 `ko_kr.json`. 게임 언어 설정을 그대로 따른다.
- 화면 문구, 툴팁, 채팅 메시지, 단축키 이름은 전부 번역 키로 처리한다. 코드에 문장을 직접 넣지 않는다.
- 파일 내부 데이터(블럭 ID, 메타데이터 키)는 언어와 무관하다.
- 블럭 검색은 표시 언어와 분리되어 있다. 항상 한글/영어 이름 모두로 검색된다 (4.6 참고).

## 5. 데이터 모델

### 5.1 `.pawprint` 파일
ZIP 컨테이너다. 썸네일과 메타데이터를 전체를 풀지 않고 읽을 수 있다.

```
example.pawprint (zip)
├─ meta.json        # 메타데이터 (라이브러리 인덱싱용)
├─ blueprint.nbt    # 블럭 데이터 (gzip NBT)
└─ thumbnail.png    # 썸네일 (선택)
```

**meta.json**
```json
{
  "format": 1,
  "id": "uuid",
  "name": "Oak Cabin",
  "description": "",
  "author": "player name",
  "tags": ["house", "oak"],
  "created": "2026-10-07T12:00:00Z",
  "modified": "2026-10-07T12:00:00Z",
  "mcVersion": "1.21.1",
  "dataVersion": 3955,
  "size": [12, 8, 10],
  "blockCount": 534,
  "removalCount": 20,
  "mods": ["minecraft", "supplementaries"],
  "origin": {
    "server": "play.example.com",
    "dimension": "minecraft:overworld",
    "pos": [120, 64, -340]
  }
}
```
- `origin`은 선택이다. 있으면 "원위치 배치"를 쓸 수 있다.

**blueprint.nbt**
- `palette`: 블럭 상태 문자열 목록 (예: `minecraft:oak_stairs[facing=east,half=bottom]`).
- `blocks`: 팔레트 인덱스 배열 (bit-packed). `-1`은 "관여 안 함"(해당 칸을 비교하지 않음).
- `removals`: 제거할 블럭 위치 목록 (그 칸은 공기여야 함).
- `blockEntities`: 선택. 위치별 NBT (표지판 글자 등).
- 알 수 없는 블럭 ID는 지우지 않고 문자열 그대로 보존한다.

### 5.2 기타 로컬 데이터
```
<게임 폴더>/pawprint/
├─ blueprints/               # 라이브러리 (폴더 = 그룹)
├─ index.json                # 라이브러리 메타데이터 캐시
├─ placements/<서버키>/<차원>.json   # 배치 상태
├─ snapshots/<id>.nbt        # 지형 스냅샷
```
- 설정 파일은 로더 표준 위치인 `<게임 폴더>/config/pawprint.json`에 둔다 (자체 JSON, 설정 라이브러리 없음).
- `서버키`: 서버 주소를 파일명에 안전한 문자열로 바꾼 것. 싱글은 월드 폴더명을 쓴다.

### 5.3 버전 호환
- 청사진에 `dataVersion`을 기록하고, 구버전 파일은 게임의 DataFixer로 블럭 상태를 업그레이드한다.
- 신버전 청사진을 구버전에서 열면 없는 블럭은 대체 블럭으로 표시하고 ID를 보존한다.

## 6. 멀티플레이 안전 원칙
- **네트워크 채널을 등록하지 않는다.** 서버에 모드가 없어도 접속되게 클라이언트 전용으로 설정한다.
- **자동 설치/설치 보조 기능을 넣지 않는다.**
- **프리캠**은 카메라만 움직이고 이동 패킷을 보내지 않는다. 설정으로 끌 수 있다.
- **지형 스냅샷**은 이미 로드된 청크만 읽고, 반경 제한과 기능 끄기 옵션을 둔다.
- 기능별 on/off 설정을 둬서 서버 규칙에 맞출 수 있게 한다.

## 8.2 표시 모드
| 모드 | 보이는 것 | 클릭 |
|---|---|---|
| 꺼짐 (기본) | 실제 블럭만 | 평소대로 |
| 배치 모드 (`J`) | 배치 오버레이 | 평소대로 (서버로 전송) — 오버레이를 보며 실제로 지을 때 |
| 편집 모드 (`G`) | 초안 + 배치 | 청사진 편집 (서버로 안 보냄) |

- 편집 모드를 끄면 배치 모드도 꺼져서 실제 블럭만 보인다.
- 라이브러리에서 "여기에 배치"를 하면 배치 모드가 자동으로 켜진다.
- 배치가 안 보일 때는 이동/회전 키도 동작하지 않는다.

## 8.3 가짜 블럭 렌더링
- 바닐라 블럭 렌더러(`ModelBlockRenderer.tesselateBlock`)로 그린다. 그 자리의 실제 밝기, 부드러운 조명의 모서리 음영,
  면별 명암, 바이옴 색이 실제 블럭과 같다.
- 가짜 블럭이 채워진 월드 뷰(`GhostWorld`)를 넘겨서, 가짜 블럭끼리나 실제 블럭과 맞닿은 면은 실제처럼 가려진다.
- 불투명도 `ghostOpacity`(기본 0.65), 밤에 잘 보이게 하는 `ghostFullBright`(기본 false).
- 셰이더팩(Iris) 환경에서는 Iris가 이 그리기를 어떻게 처리하는지에 따라 결과가 달라질 수 있어 확인이 필요하다.

## 8.4 편집 모드 구현 메모
- 클릭 가로채기: `Minecraft.startUseItem / startAttack / continueAttack / pickBlock` 시작 지점에 mixin을 건다.
  손 흔들기나 패킷 전송 전에 끊기므로 서버는 아무것도 받지 않는다.
- 초안(Draft): 월드 좌표 기준 `위치 → 블럭 상태` 맵. 공기 상태는 "제거할 블럭"을 뜻한다.
  서버·차원별로 `pawprint/drafts/`에 자동 저장한다 (변경 후 5초, 편집 모드 종료, 접속 변경 시).
- 조준: 실제 블럭은 바닐라 레이캐스트, 초안 블럭은 격자 순회로 찾아서 더 가까운 쪽을 쓴다.
  아무것도 없으면 눈앞 4.5칸 허공에 놓는다. 사거리는 `editReach`(기본 48).
- 블럭 방향: 팔레트·손에 든 블럭은 실제 설치 규칙(`getStateForPlacement`)으로 방향을 정한다. 휠 클릭으로 집은 블럭은 상태 그대로 쓴다.
- 도구: 한 칸, 선, 상자(채움), 상자(속 빔), 벽, 구, 원기둥 (`shape.Shape`, AI 형식과 공용).
  우클릭 두 번 = 채우기, 좌클릭 두 번 = 초안 블럭 지우기, 다른 버튼 = 취소. 한 번에 최대 262,144칸.
- 실행 취소 기록은 100단계.
- 팔레트: 아이템이 있는 모든 블럭. 검색은 `en_us`와 `ko_kr` 번역을 따로 읽어서 게임 언어와 상관없이 한/영 이름, ID, 초성으로 찾는다.
- 상태 비교에서 연결 속성(`north/south/east/west/up/down`, `shape`)도 무시한다. 울타리·벽·계단 모서리가 이웃에 따라 바뀌기 때문이다.
- 상태 갱신은 10틱마다 한다. 렌더는 매 프레임이지만 카메라 거리(`ghostRenderDistance`, 기본 64)와 개수(`maxGhostBlocks`, 기본 5만) 제한이 있다.
- 섹션 메시 캐시는 아직 없다 (매 프레임 블럭 모델을 다시 그림). 큰 청사진 성능은 6단계에서 다룬다.

## 9. 위험 요소
- **렌더링 호환성**: Sodium/Iris, 버전별 렌더링 변경. 0~1단계에서 프로토타입으로 먼저 검증한다.
- **블럭 상태 추론**: 설치 규칙이 플레이어 시선 등에 의존하는 모드 블럭이 있다. 상태 직접 편집으로 보완한다.
- **블럭 → 아이템 변환**: 재료 목록에서 예외가 많다. 예외 표를 두고 점진적으로 보완한다.
- **외부 포맷 명세 변경**: 포맷별 버전 필드를 확인하고, 모르는 버전은 거부하고 안내한다.
- **서버 규칙**: 프리캠, 맵 다운로드 금지 서버. 기능별 끄기로 대응한다.
